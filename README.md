# albedev/homebrew-tap

Homebrew tap for [albedev](https://github.com/albedev)'s tools.

## whaletop

🐳 btop-style terminal monitor for Docker: resources and disk usage relative to what Docker can use,
with kill / restart / rm / prune from the keyboard. → [albedev/whaletop](https://github.com/albedev/whaletop)

```sh
brew install --cask albedev/tap/whaletop
whaletop        # or the short alias: wtop
```

## ime

⌨️ Intuitive macOS editor: a terminal text editor with native Mac keybindings (⌥/⌘), mouse and trackpad,
syntax highlighting and markdown preview. → [albedev/ime](https://github.com/albedev/ime)

```sh
brew install albedev/tap/ime
ime file.txt
```

Casks in this repo are generated automatically by GoReleaser on every release: do not edit them by hand.
Formulae in `Formula/` are maintained by hand.
